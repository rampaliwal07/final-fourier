Aim

Objective

Experiment Objective

Understand Fourier Series representation and compute coefficients over any interval [a, b].

  • Define Fourier Series for periodic function with period T = b−a.
  • Compute a₀, aₙ, bₙ using Euler's formulas.
  • Verify coefficients with L = (b−a)/2.

Theory

Background

Fourier Series on [a, b]

f(x) = a₀/2 + Σ[ aₙ cos(nπx/L) + bₙ sin(nπx/L) ]    where L = (b−a)/2
a₀ = (1/L) ∫ₐᵇ f(x) dx    aₙ = (1/L) ∫ₐᵇ f(x) cos(nπx/L) dx    bₙ = (1/L) ∫ₐᵇ f(x) sin(nπx/L) dx

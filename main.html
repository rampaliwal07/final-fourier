Theory: Harmonic Analysis

📈 What is Harmonic Analysis?

Harmonic analysis is the process of expressing a periodic function as the sum of simple sine and cosine waves called harmonics. It helps to study the frequency, amplitude, and phase of periodic signals. The fundamental harmonic has the lowest frequency, while higher harmonics are integral multiples of the fundamental frequency.

📐 Fourier Series Representation

A periodic function f(x) with period 2π can be represented as:

f(x) = \frac{a_0}{2} + \sum_{n=1}^{\infty} \left( a_n \cos(nx) + b_n \sin(nx) \right)

Where:

  • a₀ = average value of the function (DC component)
  • aₙ = cosine coefficients (even part)
  • bₙ = sine coefficients (odd part)
  • n = harmonic number

🧮 Harmonic Coefficients (Euler–Fourier formulas)

a_n = \frac{1}{\pi} \int_{-\pi}^{\pi} f(x) \cos(nx) \, dx, \quad b_n = \frac{1}{\pi} \int_{-\pi}^{\pi} f(x) \sin(nx) \, dx

For discrete data (numerical harmonic analysis):
a₀ ≈ (2∑y)/(4L), aₙ ≈ (2/L)∑ y·cos(nπx/L), bₙ ≈ (2/L)∑ y·sin(nπx/L).

🎵 Applications

Harmonic analysis is widely used in signal processing, sound analysis, electrical systems, communication engineering, and solving partial differential equations. It simplifies complex waveforms into manageable frequency components.

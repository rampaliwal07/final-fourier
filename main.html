Aim

Objective of the experiment

Experiment Objective

The aim of this virtual lab is to understand the Fourier Series representation of periodic functions and to compute Fourier coefficients numerically.

By the end of this experiment, students will be able to:

  • Define Fourier Series for a periodic function f(x) with period 2L.
  • Compute the coefficients a₀, aₙ, bₙ using Euler's formulas.
  • Approximate a given function using finite number of terms.
  • Verify correctness of coefficients through interactive checks.

Theory

Background concepts & definitions

Fourier Series

Any periodic function f(x) with period 2L can be represented as an infinite sum of sines and cosines:

f(x) = a₀/2 + Σ[ aₙ cos(nπx/L) + bₙ sin(nπx/L) ]    (n=1 to ∞)

Euler's Formulas (π = 3.14 used in simulation)

a₀ = (1/L) ∫₋ᴸᴸ f(x) dx     aₙ = (1/L) ∫₋ᴸᴸ f(x) cos(nπx/L) dx     bₙ = (1/L) ∫₋ᴸᴸ f(x) sin(nπx/L) dx

Key Properties:

  • For even functions, bₙ = 0.
  • For odd functions, a₀ = 0 and aₙ = 0.
  • The series converges to f(x) at points of continuity.

In this simulation, we numerically integrate using Simpson's rule with π = 3.14.
